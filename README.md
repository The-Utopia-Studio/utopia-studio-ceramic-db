# The Utopia Studio Design Assets

The source-of-truth asset library for the Ceramic Utopia and Utopia Cloudblur brand rooms.

Repository: https://github.com/The-Utopia-Studio/utopia-studio-ceramic-db

Migrated from `aiden150/design-asset` at `4148bc44581b4d76e9d7acb2402544319dde58e6`, preserving the complete Git history and all asset paths.

## Structure

- `logos/brand` — official The Utopia Studio identity files
- `logos/partners` — approved partner and technology logos
- `images/illustrations` — illustrations and generated editorial imagery
- `photos/team` — team, workplace, and portrait photography
- `photos/events` — event and documentary photography
- `videos/illustrations` — motion counterparts for illustration assets

The brand room reads `asset-manifest.json` and preserves this folder hierarchy.
Do not move or rename an asset without updating the manifest in the same commit.

## Usage

These files were supplied for The Utopia Studio workflows. Rights and third-party
logo permissions are not independently verified by this repository. Confirm the
intended placement before external publication.
